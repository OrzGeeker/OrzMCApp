## 概览

OrzMC 是用于 macOS/iOS 的 Minecraft Java Edition 启动器与辅助应用。macOS 启动器负责本地客户端和服务端启动、Java 运行时检测、Paper 插件下载、exaroton 远程托管服务集成，以及 Developer ID + Sparkle 的独立分发更新链路。

本文档是项目唯一长期维护的文档入口。后续架构、发布、工作流和维护说明都应直接写入 DocC，并随 App target 一起构建发布到 GitHub Pages。
